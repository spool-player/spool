# Support Policy

Spool is prerelease software. The latest `v0.x` prerelease is the only supported binary release; `master` is development code.

Use GitHub issues for reproducible project defects and feature requests. General Jellyfin server administration, media encoding, network configuration, and unsupported operating-system questions belong in the appropriate Jellyfin community support channel.

Support is best effort. Reports must identify the app version, platform, expected behavior, actual behavior, and minimal reproduction steps. Review the diagnostics preview before attaching it. Never post tokens, credentials, Quick Connect values, raw logs, server addresses, account/library/media names, or stable item/profile IDs.

Security issues must follow `SECURITY.md` and be reported privately.
